PlugPark v0.3.4 — EV 전체 수집 / 숫자 의미 수정

핵심:
1. `56곳` 같은 숫자는 부산 전체 충전소가 아니라
   "EV가 매칭된 공영주차장 수"였습니다.
2. 화면에서 이 수치와 부산 전체 EV 충전소/충전기 수를 분리합니다.
3. 첫 1000건 quick snapshot을 전체 데이터처럼 쓰는 구조를 제거합니다.
4. getChargerInfo에 zcode=26을 넣고 pageNo를 증가시키며 부산 데이터를 끝까지 읽습니다.
5. 만약 API가 zcode 필터를 무시하면 전국 데이터를 페이지 단위로 읽고 zcode=26/부산 주소만 로컬 필터합니다.
6. 상태 API는 statId + chgerId로 정보 API와 JOIN합니다.

새 진단:
- /api/ev-summary
- /api/ev-search?q=센텀
- /api/ev-search?q=해운대

적용:
1. ZIP을 D:\Projects\PlugPark 에 덮어쓰기
2. npm run deploy
3. 배포 후 아래 확인
   https://plugpark.dtdt4865.workers.dev/api/ev-summary
   https://plugpark.dtdt4865.workers.dev/api/ev-search?q=센텀

주의:
BUSAN_REALTIME_PARKING_API_URL 설정은 EV와 별개입니다.
실시간 잔여 주차면을 쓰려면 해당 URL 설정은 여전히 필요합니다.
