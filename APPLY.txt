PlugPark v0.5.3 DIRECT D1 UPLOAD

이번 버전은 Wrangler D1 import 경로를 backfill에서 제거합니다.
로그에서 Network connection lost가 반복되고 마지막에는 OAuth Authentication error 10000까지 발생했기 때문입니다.

변경:
- Worker에 POST /api/admin/d1/ev-info-bulk-upsert 추가
- 로컬 backfill은 EV API를 1000건씩 조회
- 100건씩 Worker에 HTTPS POST
- Worker가 D1에 직접 UPSERT
- 최대 8회 자동 재시도
- 페이지 전체 업로드 성공 후에만 remote/local checkpoint 증가
- 기존 .plugpark/ev-backfill-state.json을 그대로 사용하므로 실패한 page 11부터 재개 가능

적용:
1. ZIP을 프로젝트 루트에 덮어쓰기
2. npm run deploy
3. 기존 PowerShell 환경변수 EV_CHARGER_API_KEY / PLUGPARK_INGEST_TOKEN 유지
4. npm run ev:backfill

중요: 이번 버전은 Worker endpoint가 추가되므로 deploy가 필요합니다.
