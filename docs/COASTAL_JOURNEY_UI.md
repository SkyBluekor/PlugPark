# 바닷바람 출발선 UI

선택한 02안의 여름 소년만화 분위기를 실제 입력창·지도·검색 결과에 적용했다.

- 상단: 부산 해안 배경, 여행 수첩, AI 입력창, 별도의 목적지 검색창.
- 목적지 검색: 장소명·주소를 좌표로 변환 → 주황색 목적지 핀 → 주변 3km 거리순 탐색.
- 반경: 1·3·5km 또는 전체. 목적지와 내 위치를 구분한다.
- 검색 실패는 이전 목적지를 유지하고, 검색 취소 뒤 늦게 끝난 응답은 무시한다.
- 주변 결과가 없어도 목적지 핀을 유지한다.
- 모바일에서는 풍경 아래 수첩, 지도, 목록 순서로 표시한다.
- 바람 효과와 대화 펼침에 애니메이션을 적용하고 움직임 줄이기 설정을 존중한다.

## 이미지

`public/plugpark-coastal-journey.png` — 내장 ImageGen 도구로 생성한 배경.

최종 프롬프트 요지: 부산의 여름 해안과 다리, 푸른 바다와 구름, 녹색 식생, 오른쪽에 지도를 든 짧은 머리의 소년·전기차·충전기. 원본 소년만화의 선화와 수채·과슈 배경. 왼쪽은 입력창이 놓일 공간. 글자·로고·UI 없이 배경만 생성. 후속 편집은 인물을 소년으로 조정하고 풍경을 유지.

## 확인

`npm run verify:journey-search`는 실제 App 검색 핸들러와 지도 effect를 모의 지도 SDK로 실행해 목적지·반경·취소·실패·빈 결과 동작을 확인한다.

`npm run verify:mcp-web-s21c`는 폴리텍 대학, 부산역, 행정동, 도로명 주소의 위치 해석을 모의 지도 검색으로 확인한다.

카카오 SDK 실연결은 사용자 요청에 따라 배포 후 수동 확인한다. 배포한 페이지에서 “폴리텍 대학” 검색 → 부산캠퍼스 핀 → 주변 목록 및 반경 변경 → 검색 지우기를 확인한다.

공개 서비스 배포는 커밋·푸시 후 진행하며, 카카오 SDK 실연결은 사용자가 배포 화면에서 확인한다.
